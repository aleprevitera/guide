# Clinica Medica

## Introduzione

Questa guida pratica copre gli aspetti fondamentali della Clinica Medica per il VI Anno di Medicina.

## Argomenti Principali

### Semeiotica Medica Avanzata
- Anamnesi strutturata
- Esame obiettivo completo
- Interpretazione dei segni clinici

### Patologie Cardiovascolari
- Scompenso cardiaco
- Cardiopatia ischemica
- Aritmie

### Patologie Respiratorie
- BPCO
- Polmoniti
- Insufficienza respiratoria

### Patologie Gastroenterologiche
- Cirrosi epatica
- Malattie infiammatorie croniche intestinali
- Pancreatite
